# 会员与接口门槛
> 本项目依赖人升的开放接口，而**调用接口属于人升会员能力**。这一页只讲「开工前要确认什么」。
> 权威说明见官方[《会员须知》](https://wiki.lifeupapp.fun/zh-cn/#/introduction/vip-terms)；完整权益见 App「扩展」页。
> 本页**不写价格、不复制完整权益清单** —— 一律以官方与 App 内为准。

## 一句话
**云人升免费下载；调用要会员；连通性检查也算调用。**

## 与接口相关的会员权益（官方 0–27 项中的三项）
| 项 | 原文 |
|---|---|
| 17 | 支持使用商品或外部应用调用《人升》的开放接口 |
| 21 | 支持《云人升》开发扩展工具，实现与电脑等跨设备联动（仅提供基础开发能力） |
| 23 | 通过《云人升》+ API 功能扫码购买商品、完成任务等 |

其余权益（音效、主题色、卡片背景、小部件等）见 App「扩展」页。

## 会员性质
- **一次性买断制**，无订阅；买断后永久享有「扩展」页标识的权益。
- 会员**绑定当前登录账号**，账号不可转让；虚拟商品原则上不支持退款。
- 价格与优惠以 App 内购买页为准。

## 渠道差异（容易踩坑）
| 渠道 | 获取方式 |
|---|---|
| 国内应用商店 | **内购**开通 |
| Google Play | **付费购买**（买断），无内购 |

**两个渠道的会员不互通，不能互相激活** —— 买之前先确认自己装的是哪个渠道。

## 与 ulives 的关系
- 两款是**独立应用**（独立商店 / 购买 / 许可证 / 数据），人升备份导入 ulives **不转移会员权益**。
- 两边会员**互不通用**。

## 对本项目的影响
- 没有会员：环境能装好，但**读不到数据**（`GET /info` 就会失败），无法验证连接。
- 建议顺序：**先确认会员 → 再装 Node / 配置环境**。
- MCP 工具（`@lifeup/mcp`）本身免费开源，但它读写的仍是这套接口。

## 常见误写
| 别说 | 要说 |
|---|---|
| 云人升要会员才能下载 | 下载免费，调用收费 |
| MCP 需要会员 | 工具免费，它调的接口需要会员 |
| 订阅会员 | 一次性买断 |
