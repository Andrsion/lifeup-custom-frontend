# 会员与接口门槛
> 只想确认「要不要花钱」→ 看下面第一段就够；渠道差异那节是给要排查的人看的。
> 本项目依赖人升的开放接口，而**调用接口属于人升会员能力**。这一页只讲「开工前要确认什么」。
> 权威说明见官方[《会员须知》](https://wiki.lifeupapp.fun/zh-cn/#/introduction/vip-terms)；完整权益见 App「扩展」页。
> 本页**不写价格、不复制完整权益清单** —— 一律以官方与 App 内为准。

## 一句话
**云人升本身属于会员权益（第 21 项）：国内版非会员拿不到下载入口；调用接口也要会员；连通性检查同样算调用。**

## 云人升怎么装
- 国内版：**需先有会员** —— 人升 → 侧边栏 → **设置 → 实验** →《云人升》下载按钮；非会员看不到这个入口。
- 会员权益 / 价格：人升 → 侧边栏 → **扩展** 页（官方《会员须知》为权威口径）。
- Google Play：商店搜索《云人升》（`net.lifeupapp.lifeup.http`），能否直接获取以商店页显示为准。
- 装好打开后授予人升数据权限，并开启「读取人升数据」；首页会显示 `IP:13276`。

## 与接口相关的会员权益（官方 0–27 项中的三项）
| 项 | 原文 |
|---|---|
| 17 | 支持使用商品或外部应用调用《人升》的开放接口 |
| 21 | 支持《云人升》开发扩展工具，实现与电脑等跨设备联动（仅提供基础开发能力） |
| 23 | 通过《云人升》+ API 功能扫码购买商品、完成任务等 |

其余权益（音效、主题色、卡片背景、小部件等）见 App「扩展」页。

## 会员性质
- **一次性买断制**，无订阅；买断后永久享有「扩展」页标识的权益。
- 会员**绑定当前登录账号**，账号不可转让；虚拟商品原则上不支持退款。
- 价格与优惠以 App 内购买页为准。

## 渠道差异（容易踩坑，依据官方「谷歌版本差异」表）

| 差异点 | 国内商店版 | Google Play 版 |
|---|---|---|
| 获取方式 | 免费下载 + **应用内购**会员 | **付费购买**（买断）；持有效期内的 **Google Play Pass** 可免费获取 |
| 内置会员功能 | ✔️ | ✔️ |
| **应用内更新**（会员内测通道） | ✔️ | **❌** |
| 会员说明页面 | ✔️ | **❌** |
| 提前体验新功能 | ✔️（内置更新） | ✔️（内测期按比例分阶段发布正式版） |
| 免登录使用会员功能 | ❌ | ✔️（用设备上的 Google 账号做许可校验） |
| 多语言 | 仅中英文 | 全部社区贡献语言 |

**结论**：Google Play 版**没有应用内更新通道，因此收不到「会员内测」**；但会在内测期分阶段推送正式版，仍能较早拿到新功能。

**怎么确认自己属于哪个渠道**：

1. **先看有没有为应用本身付过费** —— Google Play 版是付费应用（持有效期内的 Play Pass 可免费获取）。没付过费，基本就是国内商店版或试用版；其他地区可通过 [LifeUp 官方 GitHub Releases](https://github.com/Ayagikei/LifeUp/releases) 获取免费试用版（官方发布页标注 7 天试用）。
2. **再打开 App 的「关于」页面，看有没有「应用内更新」入口**：有 → 国内商店版；没有 → Google Play 版。
3. 辅助判断：「关于」页里有没有「会员说明」入口（国内有、Google Play 版没有）。

> 版本号本身分不出渠道（两边是同一套版本号），要看上面这几个差异。

**两个渠道的会员不互通，不能互相激活。**

> 来源：官方《应用介绍》→「[谷歌版本差异](https://wiki.lifeupapp.fun/zh-cn/#/README?id=谷歌版本差异)」。

## 独立版下载、试用与授权

> ⚠️ **版本提示**：独立版（GitHub Releases）**不跟随商店版的会员内测节奏**，以稳定版为主、按人工节奏发布。目前最新为 **v1.105.5（2026-09-04）**，而商店正式版已到 **v1.106.0**——因此独立版**低于 MCP / Skills 所需的 v1.106.0+**。走 MCP 请用商店版；独立版适合「先试用、只用基础 HTTP 查询」的场景。


独立版的下载、试用和授权方式以 [LifeUp 官方 GitHub Releases](https://github.com/Ayagikei/LifeUp/releases) 页面为准。官方发布说明包括以下内容：

### 下载与安装

1. 打开上方的官方 Releases 页面，进入要下载的版本。
2. 在该版本页面的 **Assets** 区域下载 `.apk` 安装包。
3. 在 Android 设备上使用浏览器下载并安装。系统可能会要求允许浏览器安装应用。

### 试用与授权方式

- **7 天免费试用**：试用期间可使用全部功能。
- **无需 Google Play 服务**：基础功能不依赖 Google Play 服务。
- **试用结束后的授权方式**：
  - **Google Play 购买记录识别**：登录相应账号后可自动识别购买记录。
  - **Google Play Pass 验证**：通过有效的 Google Play Pass 资格验证授权。
  - **直接购买授权**：按官方提供的方式购买许可证。

### 登录与其他注意事项

- **目前授权绑定需要使用 Google 或 Facebook 账号登录**；其他绑定方式仍在开发中。
- 进行许可证验证时，需要保持登录状态并连接互联网。
- 独立版兼容 Google Play 的购买记录。
- 支持导出数据，并在不同版本之间迁移。

> 以上说明根据 [LifeUp 官方发布页](https://github.com/Ayagikei/LifeUp/releases)整理；具体版本、可下载文件及授权规则请以对应版本的官方发布说明为准。
## 与 ulives 的关系
- 两款是**独立应用**（独立商店 / 购买 / 许可证 / 数据），人升备份导入 ulives **不转移会员权益**。
- 两边会员**互不通用**。

## 对本项目的影响
- 没有会员：环境能装好，但**读不到数据**（`GET /info` 就会失败），无法验证连接。
- 建议顺序：**先确认会员 → 再装 Node / 配置环境**。
- MCP 工具（`@lifeup/mcp`）本身免费开源，但它读写的仍是这套接口。

## 常见误写
| 别说 | 要说 |
|---|---|
| 云人升免费下载，不用会员 | 云人升是会员权益（第 21 项）；国内版非会员连下载入口都没有 |
| MCP 需要会员 | 工具免费，它调的接口需要会员 |
| 订阅会员 | 一次性买断 |
