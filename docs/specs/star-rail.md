# 🚄 崩坏：星穹铁道 · 界面规格与提示词

> 本文是《🧩 自定义界面 + AI + MCP 实现方案》([custom-ui-ai-mcp.md](../custom-ui-ai-mcp.md)) 的**主题实例**：把「完成待办 / 记习惯」包装成**乘星穹列车穿越银河的开拓之旅**。
> 玩法命名参考见 [samples.md](../samples.md) 的「崩坏：星穹铁道」案例。
> **用法**：把文末「📋 提示词」整段复制给你的 AI Agent，即可生成一个可运行的本地网页界面。

---

## 一、它是什么

人升（LifeUp）本身是"游戏化待办"，但仍是一张列表。本规格要做的，是**在你自己的电脑上跑一个本地网页**，把同一个待办系统换成"星穹列车"的皮肤与交互——**每屏是一个地点，不是一个列表**。

- 数据源：手机上的**云人升**本地 HTTP 服务（局域网）。
- 形态：本地网页（不是云端托管），双击启动。
- 主题取向：**反焦虑**——核心是"不必全勤也拿满核心奖励"，适合容易被"漏一天就崩"劝退的人。
- 第一版**只做"读 + 完成"**，跑通后再加动画 / 跃迁 / AI。

## 二、开工前：三个硬性前提

1. **手机侧达标**：人升 **v1.106.0+** × 云人升 **3.0.0+**，并在 人升 → 设置 → 实验 里开启「读取人升数据」。
2. **同一局域网**：电脑与手机连同一个 Wi-Fi（路由器开了 AP 隔离也会失败）。
3. **必须加一层本地薄代理**：浏览器直连云人升会被 **CORS** 拦，且 **Token 会暴露**。
   - 开发阶段：用 Vite 的 `server.proxy` 兼任这一层；
   - 用静态页直接打开：**另配一层薄代理**（`examples/` 里的 `proxy.js` 可参考）。
   - ⚠️ 因此**不能用**"云端生成 + 云端托管"的平台（秒哒 / Bolt.new / v0 / Lovable 等）——它们连不到你家局域网，在线预览也绕不开跨域。

## 三、接口约束（写代码前必读）

| 项 | 规则 |
|---|---|
| 读 | `GET http://<手机IP>:13276/{tasks,items,coin,skills,tasks_categories,info,...}` → `{code,message,data}`；`/tasks`、`/items`、`/skills` 等普通列表接口不分页；`/history`、`/feelings` 与 `*_records` 使用 `offset` / `limit`（默认 0 / 100） |
| 写 | `POST http://<手机IP>:13276/api/contentprovider`，body `{"url":"lifeup://api/complete?id=<任务ID>"}` → `{result}` |
| **写不幂等** | **超时不要自动重试**；「打卡 / 跃迁」按钮**点击后立即禁用**（或先确认），防双击重复完成、重复发奖 |
| Token | 云人升设了 Token 就用 **raw 头**（**不是** `Bearer`） |
| 缓存 | 用 **`gid`**（重复任务 `id` 每周期都变、`gid` 不变） |
| 取数方式 | `lifeup://` 是**动作协议**、不取数；**读数据只有云人升 HTTP** |
| 症状 | 处理方式 |
| 跃迁（抽卡） | 用**开箱接口 `loot_box`**（先手动在 App 里建好箱子的奖品池）；它是**消耗型写操作**，同样防重复点击 |
| 双货币 | 人升**原生只有一种金币**（对应「信用点」）；「星琼」这种高阶货币需**自映射**——做成一个物品 / 合成产物，或改用 ulives（原生多货币，但本项目不覆盖 ulives，需另做）。**别假设有第二种金币** |
| 权威源 | 完整接口以官方为准 → https://wiki.lifeupapp.fun/zh-cn/guide/api_cloud.md （别臆造方法名 / 参数） |

## 四、界面结构：每屏是一个"地点"

**主屏 = 星穹列车（车厢）**

| 现实事物 | 屏幕对象 | 交互 |
|---|---|---|
| 每日任务 | 车厢里的**帕姆 / 每日实训面板** | 打卡累积**活跃度**（满 100 领星琼），进度条可视化 |
| 长期习惯 | 观景车厢的**星轨 / 窗外星球** | 点亮命途，星轨推进 |
| 今日待办 | **列车日志 / 待办便签** | 展开钉住的清单 |
| 信用点（低阶货币） | 角落的**信用点计数器** | 完成时信用点飞入、带音效 |
| 星琼（高阶货币） | 旁边的**星琼计数器** | 攒够 160 = 1 抽 |
| 抽卡 / 开箱 | 车厢里的**跃迁装置** | 消耗专票 / 星琼跃迁，出货动画 + 保底进度 |
| 商店 | **伴星百货 / 帕姆商店** | 点进商店 |
| 成就 / 收集 | **列车档案室 / 图鉴** | 点开看收藏 |
| 朋友 / 家人 | 车厢里的**乘客（姬子 / 三月七 / 丹恒…）** | 点开聊天 + 好感度 |
| 周期挑战 | **模拟宇宙 / 忘却之庭入口** | 进入双周挑战 |
| 长期主线 | **航线图（各星球站点）** | 点亮开拓任务进度 |
| 通行证 | **无名勋礼**（免费 / 68 / 128 三档） | 查看本期奖励轨道 |

**次屏**：开拓者面板（开拓等级 · 均衡等级 + 行迹 / 光锥 / 遗器 / 星魂）｜跃迁（卡池 + 保底双轨进度）｜航线图（星球站点）｜背包。

## 五、星铁机制映射（别只换皮，把机制也搬过来）

只换名字，就只是"上了皮的待办清单"；下面这些机制才是"像星铁"的关键（**这份的主题价值就在"反焦虑"**）：

- **每日活跃度制**：任务给不同活跃度，**满 100 就能领满核心奖励 —— 不必全勤**。这是整套设计的灵魂：鼓励"能做就做"，而不是"漏一天就崩"。
- **大小保底「双轨承诺」**：小保底（大概率达成）+ 大保底（必达成）；**保底进度跨期继承、中断不清零** → 中断也不白费，随时能回来。
- **任务五级分类**：主线 / 支线 / 每日 / 限时 / **随机彩蛋** —— 让清单有层次，不是一堆平铺。
- **「日 → 周 → 双周 → 版本」分层排期**：不同节奏的任务各归其位，避免所有事都挤在"今天"。
- **通行证三档**（免费 / 68 / 128）：用**同一份进度**给不同投入程度的人不同回报（可选强化）。
- **体力 = 开拓力**：给每天设消耗上限，摊平节奏。

## 六、交互细节（把它做得"像游戏"）

- **完成任务的奖励时刻（最重要）**：打卡 → **活跃度进度条涨一段** + 信用点飞入 + 经验条弹出；满 100 时给一个"今日实训完成"的庆祝反馈。
- **跃迁动画**：出货有动画，并显示**保底双轨进度**（小保底 / 大保底各到哪了）。
- **悬停 tooltip**：游戏风的物品说明框（名称 / 稀有度 / 描述）。
- **底部热键栏**：实训 / 开拓者 / 跃迁 / 航线 / 背包。
- **角落开拓力条 + 时间**：开拓力按时间恢复、设每日上限；实训与开拓力在 **04:00 刷新**。
- **每日结算**：活跃度（`x/100`）/ 信用点收入 / 经验 / 一句"今天还差 N 点活跃度拿满奖励"——**温和提示，不催命**。
- **音效**：可选、短、带静音按钮。

## 七、落地要求（面向非程序员）

- **最少文件、最少依赖**；双击启动（Windows `.bat` / macOS `.command`）；把手机 IP / 端口 / LLM Key 放进**一个配置文件**。
- **美术**：风格自选（可用科幻 UI / 扁平插画风，**不必像素**）；自己画或使用**允许商用**的免费素材，**不要使用官方美术资源**。
- **移动端**：若要在手机上用，按钮 / 区域要够大能点。
- **先只做"读 + 完成"**跑通，再加跃迁 / 动画 / AI。
