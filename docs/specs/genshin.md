# 🏔️ 原神 · 界面规格与提示词

> 本文是《🧩 自定义界面 + AI + MCP 实现方案》([custom-ui-ai-mcp.md](../custom-ui-ai-mcp.md)) 的**主题实例**：把「完成待办 / 记习惯」包装成**在提瓦特七国的冒险**。
> 玩法命名参考见 [samples.md](../samples.md) 的「原神」案例。
> **用法**：把文末「📋 提示词」整段复制给你的 AI Agent，即可生成一个可运行的本地网页界面。

---

## 一、它是什么

人升（LifeUp）本身是"游戏化待办"，但仍是一张列表。本规格要做的，是**在你自己的电脑上跑一个本地网页**，把同一个待办系统换成"提瓦特冒险"的皮肤与交互——**每屏是一个地点，不是一个列表**。

- 数据源：手机上的**云人升**本地 HTTP 服务（局域网）。
- 形态：本地网页（不是云端托管），双击启动。
- 第一版**只做"读 + 完成"**，跑通后再加动画 / 祈愿 / AI。

## 二、开工前：三个硬性前提

1. **手机侧达标**：人升 **v1.106.0+** × 云人升 **3.0.0+**，并在 人升 → 设置 → 实验 里开启「读取人升数据」。
2. **同一局域网**：电脑与手机连同一个 Wi-Fi（路由器开了 AP 隔离也会失败）。
3. **必须加一层本地薄代理**：浏览器直连云人升会被 **CORS** 拦，且 **Token 会暴露**。
   - 开发阶段：用 Vite 的 `server.proxy` 兼任这一层；
   - 用静态页直接打开：**另配一层薄代理**（`examples/` 里的 `proxy.js` 可参考）。
   - ⚠️ 因此**不能用**"云端生成 + 云端托管"的平台（秒哒 / Bolt.new / v0 / Lovable 等）——它们连不到你家局域网，在线预览也绕不开跨域。

## 三、接口约束（写代码前必读）

| 项 | 规则 |
|---|---|
| 读 | `GET http://<手机IP>:13276/{tasks,items,coin,skills,tasks_categories,info,...}` → `{code,message,data}`；`/tasks`、`/items`、`/skills` 等普通列表接口不分页；`/history`、`/feelings` 与 `*_records` 使用 `offset` / `limit`（默认 0 / 100） |
| 写 | `POST http://<手机IP>:13276/api/contentprovider`，body `{"url":"lifeup://api/complete?id=<任务ID>"}` → `{result}` |
| **写不幂等** | **超时不要自动重试**；「盖章 / 祈愿」按钮**点击后立即禁用**（或先确认），防双击重复完成、重复发奖 |
| Token | 云人升设了 Token 就用 **raw 头**（**不是** `Bearer`） |
| 缓存 | 用 **`gid`**（重复任务 `id` 每周期都变、`gid` 不变） |
| 取数方式 | `lifeup://` 是**动作协议**、不取数；**读数据只有云人升 HTTP** |
| 列表为空 / 请求失败 | 检查云人升三项授权与人升是否在后台运行 |
| HTTP 401 | Token 不匹配，检查云人升当前配置 |
| 请求超时 | 检查手机是否休眠、是否离开同一 Wi-Fi |
| 祈愿（抽卡） | 用**开箱接口 `loot_box`**（先手动在 App 里建好箱子的奖品池）；注意它是**花钱/消耗型写操作**，同样防重复点击 |
| 双货币 | 人升**原生只有一种金币**（对应「摩拉」）；「原石」这种高阶货币需**自映射**——做成一个物品 / 合成产物，或改用 ulives（原生多货币，但本项目不覆盖 ulives，需另做）。**别假设有第二种金币** |
| 权威源 | 完整接口以官方为准 → https://wiki.lifeupapp.fun/zh-cn/guide/api_cloud.md （别臆造方法名 / 参数） |

## 四、界面结构：每屏是一个"地点"

**主屏 = 冒险者营地（尘歌壶）**

| 现实事物 | 屏幕对象 | 交互 |
|---|---|---|
| 每日任务 | 冒险家协会的**每日委托板** | 点开今日委托，「盖章」= 完成；4 个全做完给额外奖励 |
| 长期习惯 | **七天神像 / 元素方碑** | 点亮，元素之力增长 |
| 今日待办 | 桌上的**冒险笔记** | 展开钉住的清单 |
| 摩拉（低阶货币） | 角落的**摩拉计数器** | 完成时摩拉飞过去、带音效 |
| 原石（高阶货币） | 旁边的**原石计数器** | 攒够 160 = 1 抽 |
| 抽卡 / 开箱 | 营地里的**祈愿台** | 消耗原石抽卡，出货动画 + 保底进度 |
| 商店 | **杂货商 / 尘歌壶商店** | 点进商店 |
| 成就 / 收集 | **图鉴 / 尘歌壶展示架** | 点开看收藏 |
| 朋友 / 家人 | 队伍里的**角色 / 邀约对象** | 点开聊天 + 好感度 |
| 周期考核 | **深境螺旋入口** | 进入本月挑战（每月重置） |
| 长期主线 | **七国地图** | 点亮各国探索进度 |

**次屏**：角色面板（冒险等阶 + 天赋 / 武器 / 圣遗物 / 命座）｜祈愿（卡池 + 保底进度）｜地图（七国 + 探索度）｜背包（圣遗物 / 材料）。

## 五、原神机制映射（别只换皮，把机制也搬过来）

只换名字，就只是"上了皮的待办清单"；下面这些机制才是"像原神"的关键：

- **双货币分层 + 单向不可回兑**：**摩拉**（低阶，只能靠做事赚）/ **原石**（高阶，可换抽卡道具）；**不设反向兑换**（防套利）。
- **「保底」抽卡**：开箱设"N 抽保底出稀有" —— 可预期地"刷"，减少挫败（比纯随机留人）。
- **「树脂」体力控节奏**：给每天设一个消耗上限 → 逼你把任务**摊到每天**，而不是一口气刷完。
- **每日委托 + 全清奖励**：每天固定几个委托，全做完给额外奖励 → 低门槛日活。
- **多维养成防数值疲劳**：冒险等阶 / 天赋 / 武器 / 圣遗物 / 命座 —— 多条成长轴，避免单点数值枯燥。
- **重复奖励可回收**：重复的材料 / 圣遗物可回收成资源（防囤积）。
- **深境螺旋（每月重置）**：月度考核 + 重置 → 制造新周期。

## 六、交互细节（把它做得"像游戏"）

- **完成委托的奖励时刻（最重要）**：委托盖章 + 摩拉飞向计数器 + 冒险阅历（经验）条弹出。
- **祈愿动画**：出货有动画，并显示**保底进度**（"再 N 抽必出"）。
- **悬停 tooltip**：游戏风的物品说明框（名称 / 稀有度 / 描述）。
- **底部热键栏**：委托 / 角色 / 祈愿 / 地图 / 背包。
- **角落体力（树脂）条 + 时间**：树脂按时间恢复、设每日上限；委托与树脂在**凌晨 4:00 刷新**。
- **每日结算**：委托完成数 / 摩拉收入 / 冒险阅历 / 一句"今日委托还差 2 个"。
- **音效**：可选、短、带静音按钮。

## 七、落地要求（面向非程序员）

- **最少文件、最少依赖**；双击启动（Windows `.bat` / macOS `.command`）；把手机 IP / 端口 / LLM Key 放进**一个配置文件**。
- **美术**：风格自选（原神是 3D 开放世界，**不必做成像素**，可用扁平插画 / UI 风）；自己画或使用**允许商用**的免费素材，**不要使用官方美术资源**。
- **移动端**：若要在手机上用，按钮 / 区域要够大能点。
- **先只做"读 + 完成"**跑通，再加祈愿 / 动画 / AI。

## 八、📋 提示词（整段复制给 Agent）

```
你是资深全栈工程师。请帮我做一个本地网页界面，我不是程序员，请用最少的文件、最简单的依赖，让我照着做就能跑起来。

【背景】
人升（LifeUp）是安卓上的游戏化任务管理 App，配套的「云人升」在手机上开了 HTTP 服务（局域网，默认端口 13276），提供两类接口：
① 读：GET http://<手机IP>:13276/tasks、/items、/coin、/skills、/tasks_categories、/info —— 返回 { code, message, data }；普通列表接口不分页；`/history`、`/feelings` 与 `*_records` 使用 offset / limit（默认 0 / 100）；
② 写：POST http://<手机IP>:13276/api/contentprovider，请求体 { "url": "lifeup://api/complete?id=<任务ID>" } —— 返回 { result }。
接口依据（重要）：以上只是常用示例，完整接口以官方文档为准 → https://wiki.lifeupapp.fun/zh-cn/guide/api_cloud.md 。写代码前先核对方法名与参数，不要臆造。

【硬性约束】
1. 浏览器直连云人升会被 CORS 拦、Token 也会暴露 → 必须把「后端薄代理 + 前端页面」做成一个本地服务，前端只访问本地服务（如 http://localhost:3000），由它转发到手机 IP:13276；不要依赖任何在线托管或云部署。
2. 写操作不幂等：超时不要自动重试；「盖章 / 祈愿」按钮点击后立即禁用，防双击重复完成、重复发奖。
3. 若云人升设了 Token，用原始 token 头（不是 Bearer）。
4. 缓存与跨周期操作用 gid（重复任务的 id 每周期会变、gid 不变）。
5. 把「列表为空 / 请求失败」等失败状态翻译成用户看得懂的提示；HTTP 401 表示 Token 不匹配；请求超时则提示检查手机休眠状态与同一 Wi-Fi 连接。
6. 人升原生只有一种金币（对应「摩拉」）；「原石」这类高阶货币请做成一个物品或合成产物来映射，不要假设有第二种金币。

主题：你是旅行者，在提瓦特七国冒险、结识伙伴、祈愿、挑战深境螺旋。
总体原则：每个页面是一个「地点」，不是一张列表；任务活在画面里的物件上。

- 摩拉 = 角落摩拉计数器（完成时飞过去、带音效）；

- 祈愿 = 营地里的祈愿台（抽卡机）：消耗原石抽卡，出货有动画，并显示保底进度（"再 N 抽必出"）；

- 深境螺旋 = 月度挑战入口（每月重置）；七国地图 = 长期主线的探索进度。

【工程要求】
```
