# 🌾 星露谷农场界面 · 规格与提示词

> 本文是《🧩 自定义界面 + AI + MCP 实现方案》([custom-ui-ai-mcp.md](../custom-ui-ai-mcp.md)) 的一篇**主题实例**：把「完成待办 / 记习惯」包装成**经营一座星露谷农场**。
> 玩法命名参考见 [samples.md](../samples.md) 的「星露谷物语」案例。
> **用法**：把文末「📋 提示词」整段复制给你的 AI Agent，即可生成一个可运行的本地网页界面。

---

## 一、它是什么

人升（LifeUp）本身是"游戏化待办"，但仍是一张列表。本规格要做的，是**在你自己的电脑上跑一个本地网页**，把同一个待办系统换成"农场"的皮肤与交互——**每屏是一个地点，不是一个列表**。

- 数据源：手机上的**云人升**本地 HTTP 服务（局域网）。
- 形态：本地网页（不是云端托管），双击启动。
- 第一版**只做"读 + 完成"**，跑通后再加动画 / AI。

## 二、开工前：三个硬性前提

1. **手机侧达标**：人升 **v1.106.0+** × 云人升 **3.0.0+**，并在 人升 → 设置 → 实验 里开启「读取人升数据」。
2. **同一局域网**：电脑与手机连同一个 Wi-Fi（路由器开了 AP 隔离也会失败）。
3. **必须加一层本地薄代理**：浏览器直连云人升会被 **CORS** 拦，且 **Token 会暴露**。
   - 开发阶段：用 Vite 的 `server.proxy` 兼任这一层；
   - 用静态页直接打开：**另配一层薄代理**（`examples/` 里的 `proxy.js` 可参考）。
   - ⚠️ 因此**不能用**"云端生成 + 云端托管"的平台（秒哒 / Bolt.new / v0 / Lovable 等）——它们连不到你家局域网，在线预览也绕不开跨域。

## 三、接口约束（写代码前必读）

| 项 | 规则 |
|---|---|
| 读 | `GET http://<手机IP>:13276/{tasks,items,coin,skills,tasks_categories,info,...}` → `{code,message,data}`；`/tasks`、`/items`、`/skills` 等普通列表接口不分页；`/history`、`/feelings` 与 `*_records` 使用 `offset` / `limit`（默认 0 / 100） |
| 写 | `POST http://<手机IP>:13276/api/contentprovider`，body `{"url":"lifeup://api/complete?id=<任务ID>"}` → `{result}` |
| **写不幂等** | **超时不要自动重试**；「照料 / 收获」按钮**点击后立即禁用**（或先确认），防双击重复完成、重复发奖 |
| Token | 云人升设了 Token 就用 **raw 头**（**不是** `Bearer`） |
| 缓存 | 用 **`gid`**（重复任务 `id` 每周期都变、`gid` 不变） |
| 取数方式 | `lifeup://` 是**动作协议**、不取数；**读数据只有云人升 HTTP** |
| 列表为空 / 请求失败 | 检查云人升三项授权与人升是否在后台运行 |
| HTTP 401 | Token 不匹配，检查云人升当前配置 |
| 请求超时 | 检查手机是否休眠、是否离开同一 Wi-Fi |
| 权威源 | 完整接口以官方为准 → https://wiki.lifeupapp.fun/zh-cn/guide/api_cloud.md （别臆造方法名 / 参数） |

## 四、界面结构：每屏是一个"地点"

**主屏 = 你的农场**

| 现实事物 | 屏幕对象 | 交互 |
|---|---|---|
| 每日任务 | 田里的作物 | 点一块地「照料」，推进生长阶段 |
| 长期习惯 | 谷仓 / 鸡舍里的动物 | 点击喂食 / 抚摸，冒爱心 |
| 今日待办 | 木告示板 | 点开看钉住的清单 |
| 金币 | 角落的金币计数器 | 带金币音效往上跳 |
| 商店 | 一栋商店建筑 | 点进商店页 |
| 成就 / 收集 | 博物馆 / 收集包柜 | 点开看收藏 |
| 朋友 / 家人 | 站在房子边的村民 | 点开聊天 + 好感爱心条 |

**次屏**：技能面板（角色 + 技能条 + 等级称号）｜商店（店主 + 图标 + "购买"确认弹窗）｜日历（季节日历，节日高亮、任务为图标）｜仓库（已买未"使用"的奖励网格）。

## 五、星露谷机制映射（别只换皮，把机制也搬过来）

只换名字，就只是"上了皮的待办清单"；下面这些机制才是"像农场"的关键：

- **28 天赛季制**：四季各 28 天，换季未完成的**季节性清空** → 制造紧迫感。
- **每日体力 + 时间预算**：原版 2:00 强制晕倒 → 给待办设"**日落结算**"，防堆量。
- **技能五维 + 专精二选一**：耕种 / 采矿 / 采集 / 钓鱼 / 战斗（各 10 级），5 / 10 级各二选一专精 → 建立"专业人设"。
- **好感度衰减**：村民好感 10 心，送礼提升、**不互动会衰减** → 适合"联系家人 / 朋友"这类习惯。
- **长期投资作物**：古代水果——播种时看不到回报、28 天后持续收益 → **训练延迟满足**。
- **加工增值**：笔记 → 整理成文 → 发布，层层放大价值。
- **爷爷评分**（第三年、可重评）→ 年度复盘，**宽容失败 / 鼓励补考**。
- **收集包逐房解锁**：社区中心 6 个房间，逐房解锁功能 → 里程碑式解锁。
- **温和惩罚**：漏做是"枯萎"而非"死亡"，留人优先（低压路线）。

## 六、交互细节（把它做得"像游戏"）

- **完成任务的奖励时刻（最重要）**：作物长一阶段 + 金币飞向计数器 + XP 条弹出。
- **悬停 tooltip**：像素风边框，像游戏里的物品说明。
- **底部热键栏**：今日 / 技能 / 商店 / 日历 / 设置。
- **角落时钟 + 体力条**：时钟跟随真实时间；体力条显示当天负荷。
- **昼夜循环**：傍晚画面变色；入夜弹"**去睡觉**"→ 触发**日结**（收入 / XP / 收获 / 一句"今天跳过了 2 块地"）。
- **音效**：可选、短、带静音按钮（金币声 + 轻背景乐很加分）。

## 七、落地要求（面向非程序员）

- **最少文件、最少依赖**；双击启动（Windows `.bat` / macOS `.command`）；把手机 IP / 端口 / LLM Key 放进**一个配置文件**。
- **像素风**：像素字体 + 有限调色板 + 粗边框；自己画或使用**允许商用**的免费素材，**不要抄原作的 sprites**。
- **移动端**：若要在手机上用，地块要够大能点。
- **先只做"读 + 完成"**跑通，再加写操作与动画。

## 八、📋 提示词（整段复制给 Agent）

```
你是资深全栈工程师。请帮我做一个本地网页界面，我不是程序员，请用最少的文件、最简单的依赖，让我照着做就能跑起来。

【背景】
人升（LifeUp）是安卓上的游戏化任务管理 App，配套的「云人升」在手机上开了 HTTP 服务（局域网，默认端口 13276），提供两类接口：
① 读：GET http://<手机IP>:13276/tasks、/items、/coin、/skills、/tasks_categories、/info —— 返回 { code, message, data }；普通列表接口不分页；`/history`、`/feelings` 与 `*_records` 使用 offset / limit（默认 0 / 100）；
② 写：POST http://<手机IP>:13276/api/contentprovider，请求体 { "url": "lifeup://api/complete?id=<任务ID>" } —— 返回 { result }。
接口依据（重要）：以上只是常用示例，完整接口以官方文档为准 → https://wiki.lifeupapp.fun/zh-cn/guide/api_cloud.md 。写代码前先核对方法名与参数，不要臆造。

【硬性约束】
1. 浏览器直连云人升会被 CORS 拦、Token 也会暴露 → 必须把「后端薄代理 + 前端页面」做成一个本地服务，前端只访问本地服务（如 http://localhost:3000），由它转发到手机 IP:13276；不要依赖任何在线托管或云部署。
2. 写操作不幂等：超时不要自动重试；「照料 / 收获」按钮点击后立即禁用，防双击重复完成、重复发奖。
3. 若云人升设了 Token，用原始 token 头（不是 Bearer）。
4. 缓存与跨周期操作用 gid（重复任务的 id 每周期会变、gid 不变）。
5. 把「列表为空 / 请求失败」等失败状态翻译成用户看得懂的提示；HTTP 401 表示 Token 不匹配；请求超时则提示检查手机休眠状态与同一 Wi-Fi 连接。

【要做的东西：星露谷农场界面】
主题：经营一座星露谷农场（继承爷爷的农场、融入鹈鹕镇）。
总体原则：每个页面是一个「地点」，不是一张列表；任务活在画面里的物件上。
主屏（农场）：
- 每日任务 = 田里的作物：点一块地「照料」推进生长阶段，成熟后「收获」= 完成任务；
- 长期习惯 = 谷仓 / 鸡舍的动物：点击喂食 / 抚摸，冒爱心；
- 今日待办 = 木告示板：点开看钉住的清单；
- 金币 = 角落金币计数器（完成时金币飞过去、带音效）；
- 商店 = 一栋商店建筑，点进商店页；
- 成就 / 收集 = 博物馆 / 收集包柜；
- 朋友家人 = 站在房子边的村民，点开聊天 + 好感爱心条。
次屏：技能面板（角色 + 技能条 + 等级称号）｜商店页（店主 + 图标 + 购买确认弹窗）｜季节日历（节日高亮、任务打图标）｜仓库（已买未用的奖励网格）。
机制（尽量体现）：任务按「作物生长阶段」反馈；好感会衰减；漏做的作物「温和枯萎」而非死亡；入夜弹「去睡觉」触发日结（今日收入 / XP / 收获 / 一句"今天跳过了 N 块地"）。
美术：像素风（像素字体 + 有限调色板 + 粗边框），自己生成或使用允许商用的免费素材，不要抄袭原作 sprites。

【工程要求】
- 做成双击就能启动：Windows 给 .bat、macOS 给 .command，别让我配运行环境（依赖越少越好）；
- 手机 IP、端口、LLM Key 放在一个配置文件里，方便我自己改；
- 先只实现第 1、2 项（读取农场数据 + 「照料 / 收获」完成按钮），跑通后再帮我加动画与 AI 助手；
- 最后给我「双击启动 → 浏览器打开本地地址」两步说明。
```
