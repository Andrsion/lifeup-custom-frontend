# 理论 → 实践：把书里的方法变成人升任务

> 读过的书，怎么落到「今天具体设哪个任务、奖励给多少」？本文把 16 本书的方法论，逐本翻译成一张「在人升上的用法」表——照着抄即可。

> **这是什么**：把书里的方法论，翻译成「在人升里具体怎么设任务、怎么搭体系」——每本一节、一张「在人升上的用法」表，照着抄就行。
>
> **怎么用**：想知道某本书怎么用到人升，直接问 AI「《书名》怎么用到人升」；想先扫一遍，看文末「🎯 一句话总结」。（书目来自「人升」ima 知识库的进阶书目）
>
> **收录（16 本）**：**习惯与行为** 微习惯 / 福格行为模型 / 认知觉醒 / 好好学习 / 如何想到又做到；**游戏化** 游戏化实战 / 游戏改变世界 / 游戏改变人生 / 游戏化思维；**心理学** 伯恩斯新情绪疗法 / 活出最乐观的自己 / 思维转变；**游戏设计** 任天堂的体验设计 / 游戏设计的236个技巧 / 游戏剧本怎么写；**人生决策** 高性价比人生指南。

### 一、《微习惯》—— 任务设得越小，越容易坚持

**核心观点**：将积极行为大幅缩减至"小到不可能失败"的步骤，通过意志力（而非动力）来培养习惯。

**👉 在人升上的具体用法：**

| **技巧**        | **怎么做**                                                |
| ------------- | ------------------------------------------------------ |
| **任务要"小到荒唐"** | 不要设"每天健身1小时"，设成"做1个俯卧撑"或"拉伸1分钟"。大脑觉得太简单，抵触感为零，反而容易超额完成 |
| **一次最多4个微习惯** | 人升里不要一下子建10个每日任务，建议从2\~3个微任务开始，等养成习惯再加                 |
| **微量开始，超额完成** | 设"每天读1页书"，但实际可能读了10页。一旦开始，你会自然想多做，但**目标始终是1页**，不要暗中膨胀  |
| **最忙的日子也能完成** | 如果你连"喝一杯水""写50个字"都做不到，那说明目标还不够小。微习惯的底线是：**任何情况下都能完成**  |
| **每天记录，别中断**  | 用"完成打卡"给自己正反馈，连胜记录本身就能激励你                              |

### 二、《福格行为模型》—— 行为=动机×能力×提示

**核心观点**：行为发生需要**动机（Motivation）+ 能力（Ability）+ 提示（Prompt）** 三者同时出现。

**👉 在人升上的具体用法：**

| **技巧**         | **怎么做**                                                    |
| -------------- | ---------------------------------------------------------- |
| **降低能力门槛**     | 人升任务如果太大，你就会抗拒。把"写一篇文章"拆成"打开文档写一句话"，能力门槛降到最低               |
| **给任务加"提示"！**  | 在任务备注里写"吃完早餐后立刻做"或"下班到家就打卡"。把新任务**锚定在已有习惯后面**，自然触发         |
| **动机不可靠，别依赖它** | 今天是周末、心情好，动力满满；但周一下班累成狗，动力为零。所以**不要靠"等有动力了再做"，而是靠任务设得足够小** |
| **消除坏行为的提示**   | 如果你总忍不住刷手机，就把手机放在另一个房间。**没有提示，就没有行为**                      |
| **完成后来个"庆祝"**  | 福格说完成微行为后要**立刻庆祝**（比如"耶！"一声），大脑会记住这种愉悦感。人升里可以配合金币奖励或成就解锁   |

### 三、《游戏化实战》—— 八角行为分析法

**核心观点**：游戏化不是贴积分、勋章、排行榜（PBL）就完事了，而是要利用**8大核心驱动力**让用户发自内心地想做一件事。

**👉 在人升上的具体用法（8大驱动力逐一对照）：**

| **核心驱动力**      | **在人升里怎么用**                                   |
| -------------- | --------------------------------------------- |
| **① 史诗意义与使命感** | 每个任务组起个有使命感的名字，比如"自我进化计划""守护者日常"，让普通任务变得有意义   |
| **② 进步与成就感**   | 用好**成就系统**！每完成一个里程碑就解锁一个成就，看到进度条在涨本身就是奖励      |
| **③ 创意授权与反馈**  | 任务**自定义**——自由选择做什么、什么时候做，还可以自己设计成就图标，发挥创造力    |
| **④ 所有权与拥有感**  | 赚金币买装备、装饰物品，你对"自己的东西"会有更强烈的拥有感，激励你继续赚金币       |
| **⑤ 社交影响与关联性** | 如果你有朋友也用，可以**互相看成就**，或者组队做任务，同伴压力也是动力         |
| **⑥ 稀缺性与渴望**   | 设置**限时任务**或"限定版成就"（比如"周末早起挑战"），让人产生"错过就亏了"的感觉 |
| **⑦ 未知与好奇心**   | 设置**隐藏成就**！不看攻略不知道触发条件，完成时会有惊喜感               |
| **⑧ 亏损与逃避心**   | 人升的**连续打卡天数**——断了就要重来，这个机制本身就是"损失厌恶"，让你不想断    |

> **小提示**：优先用上面4个驱动力（白帽，积极正面），少用下面4个（黑帽，容易让人焦虑），这样体验更好

> 🔗 完整框架（8 大核心驱动力全表 + 白帽/黑帽 + 左脑/右脑 + 设计流程）见《游戏化实战 · 核心笔记（八角行为分析法）》。

### 四、《游戏改变世界》—— 为什么要把生活当游戏

**核心观点**：游戏之所以让人上瘾，是因为它有**目标、规则、反馈系统和自愿参与**这4大特征，能带来心流体验和积极情感。现实世界缺乏这些，所以我们要用游戏化来弥补。

**👉 在人升上的具体用法：**

| **技巧**     | **怎么做**                                                 |
| ---------- | ------------------------------------------------------- |
| **明确目标**   | 每个人升任务都要有清晰的目标。不要笼统写"学习"，要写"背10个单词"或"看1页书"              |
| **设定规则**   | 自己定规则：比如"每天完成3个日常任务就能解锁一个成就""连续7天打卡获得额外奖励"              |
| **即时反馈**   | 人升的**金币+经验值+音效**就是即时反馈。每完成一个任务，系统告诉你"你进步了"，这种反馈让人想继续    |
| **自愿参与**   | 这是最重要的一点——**没有人逼你用人升**。所以任务是你自己选的，不是别人安排的，自愿参与会让你更有主人翁感 |
| **追求"心流"** | 任务难度要适中：太简单无聊，太难想放弃。**设在你踮踮脚能够到的水平**，最容易进入心流状态          |

### 五、《游戏改变人生》—— 把现实挑战当成一场游戏

核心观点：简·麦戈尼格尔（SuperBetter 作者）提出"游戏式复原力"——游戏能强化意志力、提升自尊、改善注意力、减少焦虑；用挑战心态面对障碍，你比自己想象的更强大，身边都是潜在盟友。

👉 在人升上的具体用法：

| **技巧** | **怎么做**                                                    |
| ------ | ---------------------------------------------------------- |
| 挑战心态   | 把任务当"游戏关卡"而非"义务"——完成是"过关"，没完成是"挑战失败可以重来"，不要把它当成人格失败        |
| 自我效能文案 | 给成就/称号起"你比自己想象的更强大"式的名字，强化玩家身份认同                           |
| 招募盟友   | 把"求监督"做成任务：发布"监督我今晚早睡"，让朋友领取（呼应 SuperBetter 盟友机制，人升世界模块可做） |
| 游戏式复原力 | 失败不可怕——把"没打卡"当成"这关没过，下次再来"，配合人升的补打卡/惩罚机制使用                 |

### 六、《认知觉醒》—— 成长的本质是认知升级

核心观点：人脑由本能脑/情绪脑/理智脑三层构成，理智脑最年轻、控制力最弱——所以"道理都懂却做不到"是生理常态；真正的成长靠：舒适区边缘（难易匹配）、消除模糊（焦虑源于模糊）、即时反馈、元认知（对思考的思考）。

👉 在人升上的具体用法：

| **技巧** | **怎么做**                                         |
| ------ | ----------------------------------------------- |
| 舒适区边缘  | 任务难度设在你"踮踮脚够得着"的位置——太简单无聊，太难想放弃（与《游戏改变世界》的心流呼应） |
| 消除模糊   | 把模糊目标写具体："学习"改成"背10个单词"，焦虑感会大幅下降                |
| 即时反馈   | 完成任务的反馈要"即时可见"——金币+经验+音效的组合本身就是反馈回路             |
| 元认知复盘  | 每周用"对思考的思考"复盘任务清单：哪些任务在拖延？为什么？调整设计而非硬扛          |

### 七、《如何想到又做到》（7种武器）—— SCIENCE 模型

核心观点：肖恩·扬提出7种改变行为的心理武器（SCIENCE）——阶梯模型（拆小步骤）、社交磁力（同路人）、要事为先、极度容易、神经记忆、行为在前、致命吸引。武器组合越多，行为改变越持久。

👉 在人升上的具体用法：

| **技巧** | **怎么做**                                  |
| ------ | ---------------------------------------- |
| 阶梯模型   | 梦想→目标→步骤三层拆解，人升里用"长期目标→阶段目标→每日小任务"三层任务结构 |
| 社交磁力   | 加入同路人——人升世界模块领/发任务、组队打卡，让"别人也在做"成为动力     |
| 极度容易   | 降低任务门槛到"不可能失败"（与微习惯一致）：1个俯卧撑、写1句话        |
| 行为在前   | 先做再想——"完成打卡"这个动作本身会改变态度，别等"有动力了"再开始      |
| 致命吸引   | 把打卡变成"根深蒂固"的仪式：固定时间+固定动作（早餐后立刻打卡）        |

### 八、《任天堂的体验设计》—— 让人"不由自主"地投入

核心观点：前 Wii 策划玉树真一郎总结任天堂体验设计三方法论——直觉设计（任何人都会用）、惊喜设计（意料之外情理之中）、故事设计（让人沉浸）；"不由自主地行动、不由自主地沉迷、不由自主地叙述"才是体验设计的力量。

👉 在人升上的具体用法：

| **技巧**  | **怎么做**                                           |
| ------- | ------------------------------------------------- |
| 直觉设计    | 任务界面越"不用教"越好——一键打卡、常用操作放显眼位置，降低使用成本               |
| 惊喜设计    | 随机奖励/隐藏成就（游戏化实战的⑦未知驱动力）——开箱系统就是惊喜设计的落地            |
| 故事设计    | 给任务组起有世界观的名字（天工开物的"宗门委托/三系称号"就是故事设计）——让打卡成为剧情的一部分 |
| 不由自主地叙述 | 完成后的成就展示/分享设计——让用户"想跟别人说"，自带传播力                   |

### 九、《高性价比人生指南》—— 先筛出「值得做的事」，再搬进人升

**核心观点**：可做的事千千万，值不值得做差别极大——这本书把 676 条建议按 **成本 / 收益 / 证据等级（A/B/C）** 排了序，帮你把精力先花在「证据硬、成本低、收益大」的事上。

**👉 在人升上的具体用法：**

| **技巧**           | **怎么做**                                                         |
| ---------------- | --------------------------------------------------------------- |
| 用性价比筛任务          | 别让清单被「看起来很努力」的事塞满——优先把「证据 A 级 + 成本低」的事（系安全带 / 头盔、量血压、按时睡）设成每日任务 |
| 借「证据等级」给任务分级     | 给任务打 `A / B / C` 标签：A = 有硬证据（疫苗、筛查），C = 存疑——避免为伪科学习惯白耗精力        |
| 用「成本」列反推奖励       | 成本 = 钱 / 时间 / 毅力；成本越低的任务奖励给少、越难的给多，奖励才不失衡                       |
| 按处境挑一节做专项        | 全书 34 节覆盖 安全 · 健康 · 理财 · 法律 · 家庭 · 职业，按当前阶段选一节，做成一个「清单」当赛季目标    |
| 第 6 节「反面清单」当戒除任务 | 把「别做什么」直接搬成负向任务（扣钱 / 扣血）                                        |

### 十、《游戏化思维》—— 像游戏设计师一样搭你的体系

**核心观点**：游戏化不是贴积分徽章，而是用游戏设计师的思维——分清「内在动机 vs 外在动机」，配一套「游戏元素工具箱」，按 6 大步骤搭系统（定目标 → 划行为 → 懂玩家 → 设计动机回路 → 别忘乐趣 → 部署工具）。

**👉 在人升上的具体用法：**

| **技巧**  | **怎么做**                                       |
| ------- | --------------------------------------------- |
| 分清内外动机  | 先问「我是真想做事，还是为奖励才做」——内在动机的事别压太重的外部奖励，免得奖励挤走兴趣  |
| 6 步搭系统  | 给自己的体系过一遍 6 步；在人升里就是 清单 → 任务 → 奖励 → 反馈 的闭环    |
| 游戏元素工具箱 | 徽章 / 等级 / 进度条 / 排行榜按需取用、别全堆——人升的成就、等级、进度条正好对应 |
| 动机回路要闭合 | 任务 → 金币 → 奖励 → 更想做事，断一环就没黏性                   |

### 十一、《伯恩斯新情绪疗法》—— 把「情绪记录」做成每日任务

**核心观点**：情绪由想法决定，抑郁焦虑多来自 10 种「认知扭曲」；用三栏法（事件 / 自动化思维 / 理性回应）记录并反驳，可以自助改善情绪。

**👉 在人升上的具体用法：**

| **技巧**   | **怎么做**                                    |
| -------- | ------------------------------------------ |
| 情绪日记任务化  | 建「每日情绪记录」任务：发生了啥 → 当时想到啥 → 有没有踩认知扭曲        |
| 认知扭曲自查清单 | 把 10 种扭曲（非黑即白 / 灾难化 / 以偏概全…）做成清单或成就，每次对照一遍 |
| 三栏法当模板   | 用「事件 / 自动化思维 / 理性回应」三栏当任务备注模板，一键记录         |
| 情绪急救动作   | 把「一情绪波动就打开记录表写 3 行」设成固定动作，替代刷手机            |

### 十二、《活出最乐观的自己》—— 用 ABCDE 训练乐观

**核心观点**：乐观可以练——先看清自己对坏事的「解释风格」（永久性 / 普遍性 / 人格化），再用 ABCDE（事件-信念-结果-反驳-激发）把它掰回来。

**👉 在人升上的具体用法：**

| **技巧**      | **怎么做**                                           |
| ----------- | ------------------------------------------------- |
| ABCDE 当每日任务 | 每天挑一件不顺的事：A 事件 → B 想法 → C 结果 → D 反驳 → E 激发，像打卡一样做 |
| 抓「解释风格」     | 复盘时看是否把坏事说成「永远、所有事、都怪我」，是就改成「暂时、这件、只是这次」          |
| 和习惯养成配合     | 一边做小任务积累成功体验，一边用 ABCDE 化解挫败，双管齐下                  |
| 给「反驳」设奖励    | 每成功反驳一次消极想法，给自己记一笔小奖励                             |

### 十三、《好好学习》—— 用「反思」和「绿灯思维」搭知识体系

**核心观点**：拉开差距的是「临界知识」和「能力圈」；用绿灯思维（先接受、区分「我」与「我的观点」）、以慢为快、每日反思校正假设，才能把知识打通。

**👉 在人升上的具体用法：**

| **技巧** | **怎么做**                                  |
| ------ | ---------------------------------------- |
| 每日反思任务 | 建「每日 / 每周反思」，固定问：今天哪个假设被证明错了？（反思 = 校正假设） |
| 绿灯思维清单 | 遇到反对意见先程序化地「接受」再评估——做成一条 checklist 任务    |
| 能力圈可视化 | 用清单 / 属性表达你的「能力圈」，圈外的事设成「学习型任务」          |
| 以慢为快   | 少而深的长期任务给高奖励，广而浅的别贪多                     |

### 十四、《游戏设计的236个技巧》—— 把任务表设计得「好玩」

**核心观点**：汇聚 236 个游戏设计细节（机制 / 数值 / 交互 / 反馈），核心是让人「愿意一直玩」——关键在即时反馈、难度曲线与数值平衡。

**👉 在人升上的具体用法：**

| **技巧** | **怎么做**                                |
| ------ | -------------------------------------- |
| 即时反馈   | 每完成一个任务都要有明确反馈（经验 / 金币 / 音效），人升天然有，别关掉 |
| 难度曲线   | 任务难度要有起伏，别全是苦差、也别全是轻松，穿插「跳一跳够得着」的      |
| 数值平衡   | 奖励别通胀：难度 ↑ 奖励 ↑，否则金币贬值、激励失效            |
| 制造惊喜   | 偶尔给随机奖励 / 彩蛋（开箱、盲盒任务），制造「意外之喜」         |

### 十五、《游戏剧本怎么写》—— 给任务起名和包装

**核心观点**：游戏叙事靠世界观、角色和台词让人代入——把枯燥的目标变成「故事里的任务」，动力完全不同。

**👉 在人升上的具体用法：**

| **技巧**    | **怎么做**                                 |
| --------- | --------------------------------------- |
| 给任务起「故事名」 | 别叫「喝 8 杯水」，叫「为冒险者补满魔力」——同一个任务，换个名字干劲就不同 |
| 清单 = 章节   | 把清单当「章节 / 地图」、任务当「关卡」，串成一条主线            |
| 先定一句话世界观  | 参考[世界观 / 主题参考](samples.md)，先定主题再套任务名     |
| 统一语气      | 体系内所有任务用同一个「角色语气」（如 RPG 的勇者），沉浸感更强      |

---

### 十六、《思维转变》—— 给「戒手机」体系当背景

**核心观点**：数字时代大脑仍有可塑性——社交网络、游戏会持续重塑注意力与奖赏回路。（这本偏科普，落点更多是「理解为什么会上瘾」。）

**👉 在人升上的具体用法：**

| **技巧**         | **怎么做**                        |
| -------------- | ------------------------------ |
| 理解「为什么戒不掉」     | 明白刷手机是「即时反馈」在劫持奖赏回路，再有针对性地设计对抗 |
| 给易上瘾 App 设惩戒任务 | 把「无意义刷手机超时」设成负向任务（扣金币 / 扣血）    |
| 用环境替代意志力       | 手机放远、关通知——做成「每日数字节食」任务         |
| 别硬刚意志力         | 靠自动化和环境改造，而不是「我要忍住」            |
