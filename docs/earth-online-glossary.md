# 地球 Online · 梗词表（Glossary）

> **地球 Online（Earth Online / 地球OL）不是真游戏** —— 它是网友用游戏术语解构人生的**公共梗文化**：强制登录、无法退游、不能删档、开局随机、**一命通关**。
>
> 本页把常用梗词整理成「**游戏说法 → 现实含义 → 可怎么用**」，供你做自定义界面 / 玩法命名与文案时参考。
>
> ⚠️ 收录的均为**网络通用梗表达**；本页不含任何平台账号或链接，可自由用于自己的玩法。

## 六、可直接用的文案模板

**① 一星差评体** —— 当每日 / 每周复盘模板
```
【人升】★☆☆☆☆
{今天 / 这周做了什么}，太肝了，差评。
```

**② NPC 觉醒文学** —— 当激励语 / 开机提醒
> 「切换玩家模式，夺回主视角。」
> 「别在 NPC 身上浪费时间。」

**③ 系统公告体** —— 当通知 / 提醒
```
【系统公告】玩家「你」的体力已降至 20%，
请及时下线（睡觉）以恢复状态。
```
