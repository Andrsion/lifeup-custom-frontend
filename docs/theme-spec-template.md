# 主题规格模板

> 本模板用于把主题灵感变成可由 AI 重复施工的界面规范。主题文案可以自由创作，但接口和数据结构不能由主题设定改变。

- 主题名称：
- 作品 / 世界观来源（可选）：
- 一句话体验：
- 目标设备：手机网页 / 桌面 / 平板大屏
- 目标用户：
- 参考链接 / 图片（确保有使用权）：

- 主色 / 辅助色 / 强调色：
- 背景与卡片材质：

- 圆角、边框、阴影：

- 暗色 / 亮色模式：
- 小屏与大屏布局：

## 4. 页面与能力

为每个页面分别填写：

- 页面名称与目标：
- 使用哪些真实数据：

- 写操作（必须列明用户主动触发的动作）：
- 空状态：
- 加载状态：

建议先完成一个真实数据可用的最小版本，再逐步增加装饰和动效。

## 5. 数据与接口约束

- 所有接口和参数依据：[官方云人升 HTTP 文档](https://wiki.lifeupapp.fun/zh-cn/guide/api_cloud.md)。
- URL Scheme 动作依据：[人升官方 API 文档](https://wiki.lifeupapp.fun/zh-cn/guide/api.md)。
- 若官方文档提示内容可能滞后，核对其指向的官方 SDK 源码。
- 不根据主题自行改写字段名或推测不存在的字段。
- 对未知字段采用可恢复的降级展示，不阻止整页运行。
- 任务名、属性名等接口文本是不可信输入，必须安全渲染。
- 写操作结果必须按官方响应契约判断；超时后不自动重试。

## 6. 验收标准

- [ ] 主题风格明确，术语统一。
- [ ] 真实数据与装饰性内容分离。
- [ ] 页面能适配目标屏幕。
- [ ] 加载、空数据、错误状态齐全。
- [ ] 写操作有确认状态，失败不会显示成功。
- [ ] 没有把 Token 暴露到前端。
- [ ] 接口细节已按官方资料核对。
- [ ] 提供启动步骤和已知限制。
