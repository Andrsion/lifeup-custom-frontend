# 世界观 / 主题参考

> 做自己的界面或一套玩法，先给它一个**世界观** —— 同一套功能，换个说法，体验完全不同（原理见《自定义人升 · 组件清单 & 灵感库》里的「胜负在叙事」）。
>
> 下面按**传播广度**排序：越靠前，越多人一看就懂、拿来即用。

## 五、案例拆解：怎么把功能"换名"成游戏

> 挑的都是**你可能玩过**的游戏。每张表左边是你界面里本来就有的功能，右边是它在这个游戏里叫什么 —— **照着换名 + 换皮肤，界面立刻"入戏"**。

### 1. 原神

- **世界观**：旅行者游历**提瓦特七国**，收集持「神之眼」的伙伴（七元素：风 / 岩 / 雷 / 草 / 水 / 火 / 冰）。

| 常规叫法 | 原神叫法 |
| --- | --- |
| 每日任务 | 每日委托 |
| 待办 / 支线 | 世界任务 |
| 长期目标 | 魔神任务（主线）/ 传说任务 |
| 抽卡开箱 | 祈愿（纠缠 / 相遇之缘） |
| 金币 | 摩拉 |
| 高级货币 | 原石（可换抽卡道具） |
| 属性 / 等级 | 冒险等阶 · 世界等级 |
| 养成分支 | 天赋 / 武器 / 圣遗物 / 命座 |
| 体力 | 树脂 |
| 周期考核 | 深境螺旋（每月重置） |

- **可搬的机制**：**多货币分层 + 单向不可回兑**（防套利）；**90 / 180 抽保底**（开箱设"N 箱保底出稀有"）；**每日委托 + 体力**控节奏；**多维养成**防数值疲劳；重复奖励可回收。
- **适合**：想做**抽卡开箱 / 分层经济**的体系。

### 2. 崩坏：星穹铁道

- **世界观**：你是「开拓者」，乘**星穹列车**穿越银河，沿「开拓」星神的道路逐星解决「星核」危机 ——「愿此行，终抵群星」。七种**命途**即七种战斗职业。

| 常规叫法 | 崩铁叫法 |
| --- | --- |
| 用户 / 身份 | 开拓者 |
| 每日任务 | 每日实训（活跃度制，04:00 刷新） |
| 待办 / 支线 | 冒险任务 |
| 长期目标 | 开拓任务（主线）/ 同行任务 |
| 抽卡开箱 | 跃迁（星轨通票 / 专票） |
| 金币 | 信用点 |
| 高级货币 | 星琼（160 = 1 抽） |
| 属性 / 等级 | 开拓等级 · 均衡等级 |
| 养成分支 | 行迹 / 光锥 / 遗器 / 星魂 |
| 体力 | 开拓力 |
| 周期挑战 | 模拟宇宙 / 忘却之庭（双周） |
| 付费通行证 | 无名勋礼（免费 / 68 / 128 三档） |

- **可搬的机制**：**大小保底"双轨承诺"**（小保底大概率达成 + 大保底必达成）；**保底跨期继承**（中断不清零）；**任务五级分类**（主线 / 支线 / 每日 / 限时 / 随机彩蛋）；**每日活跃度制**（不必全勤也拿满核心奖励，降低全勤焦虑）；"日 → 周 → 双周 → 版本"分层排期。
- **适合**：想降低"漏一天就崩"焦虑的体系。

### 3. 绝区零（ZZZ）

- **世界观**：近未来灾变都市，唯一幸存都市「新艾利都」；你是引导他人进出超自然灾害「空洞」的**绳匠**，与各阵营**代理人**并肩作战。

| 常规叫法 | 绝区零叫法 |
| --- | --- |
| 用户 / 身份 | 绳匠 |
| 每日任务 | 每日任务（咖啡 / 刮刮卡 / 录像店 / 委托） |
| 待办 | 委托（主线 / 作战 / 探索 / 信赖 / 都市 / 代理人 六分类） |
| 长期目标 | 法厄同纪事（主线）/ 代理人秘闻 |
| 抽卡开箱 | 调频（原装 / 加密母带） |
| 金币 | 丁尼 |
| 高级货币 | 菲林（160 = 1 抽） |
| 属性 / 等级 | 绳网等级（解锁新玩法） |
| 养成分支 | 音擎 / 驱动盘 / 影画 / 邦布 |
| 体力 | 电量（+ 咖啡每日 buff） |
| 周期挑战 | 式舆防卫战 / 零号空洞 |

- **可搬的机制**：**委托六分类**（重要剧情 / 作战 / 探索 / 人际 / 生活杂务）；**三级节奏**（日活 5 分钟 + 周挑战 + 双周大考）；**每日限量 buff**（先领咖啡再做任务）；**随机词条装备卡**（凑套装激活加成，开盲盒乐趣）；**"只能肝不能氪"**的奖励（维护付出感）；**概率与保底进度公示**（"再完成 3 个必得 XX"）。
- **适合**：想让每日流程"轻但有趣"的体系。

### 4. 魔兽世界

- **世界观**：艾泽拉斯，联盟与部落 —— MMORPG 长线运营的教科书。

| 常规叫法 | 魔兽叫法 |
| --- | --- |
| 每日任务 | 日常任务 / 世界任务 |
| 每周任务 | 周常 |
| 待办清单 | 任务日志 |
| 长期目标 | 战役主线 |
| 声望 / 好感 | 声望（解锁货币兑换） |
| 副本挑战 | 地下城 / 团本 / 大秘境 |
| 周结算奖励 | 宏伟宝库（从候选里自选一件） |
| 进阶货币 | 纹章 / 神勇石（分四档） |
| 赛季 | 赛季（旧货币清零） |

- **可搬的机制**：**多货币互不兑换**；**日 / 周 / 赛季三重时钟**；**周结算自选宝箱**（极强留驻钩子）；**任务分级 + 冷却**防无限肝；"能力 → 解锁 → 更高货币"的螺旋。
- **适合**：想要**长期留存 / 赛季制**的体系。

### 5. 动物森友会

- **世界观**：参加「无人岛移居套餐」，从一顶帐篷白手起家，与现实时间同步经营岛屿。

| 常规叫法 | 动森叫法 |
| --- | --- |
| 首页 | 营地 / 岛屿 |
| 每日必做 | 每日琐事（签到 / 挖化石 / 摇树…） |
| 长期目标 | 房贷分期（8 级） |
| 金币 | 铃钱 |
| 成就 / 积分 | 里数（连续签到有奖励） |
| 待办 | 岛屿建设（建桥 / 坡道） |
| 图鉴收集 | 博物馆捐赠（鱼 / 虫 / 化石 / 艺术品） |
| 综合评价 | 岛屿评分（五星制） |
| 限时活动 | 节日 / 季节限定 |

- **可搬的机制**：**现实时间同步**（5:00 刷新）；**每日必做清单**（用户不用想"今天做什么"）；**宏大目标拆成分期里程碑**；**量化评分**（还差多少到五星）；**限时节日**（错过等一年）。
- **适合**：**低压、日常、仪式感**路线 —— 不想被惩罚逼着走的人。

### 6. 宝可梦

- **世界观**：人与「宝可梦」共存的现代奇幻世界；你是训练家，从博士处领御三家，踏上收集 / 对战 / 挑战联盟之旅。

| 常规叫法 | 宝可梦叫法 |
| --- | --- |
| 任务种类 | 图鉴（分"遇见 / 完成"两档） |
| 长期目标 | 道馆挑战（8 徽章）→ 联盟 |
| 成长 / 升级 | 进化（等级 / 道具 / 亲密度触发） |
| 稀有奖励 | 闪光宝可梦（1/4096，纯外观） |
| 分支路线 | 分支进化（伊布 8 分支） |
| 协作内容 | 版本限定 + 交换 |
| 里程碑解锁 | 徽章门槛（解锁高级功能） |
| 赛季 | 世代（新地区 + 新图鉴） |

- **可搬的机制**：**图鉴补全率**驱动（80% / 100% 触发奖励）；**进化里程碑**给长期坚持即时反馈；**低概率纯外观稀有**（可预期地"刷"）；**分支进化**（同一任务多条成长线自选）；**协作才能集齐**（天然驱动社交）。
- **适合**：想让"打卡"变"养成"的体系。

### 7. Habitica

- **世界观**：没有剧情，**纯"系统层"游戏化** —— 你的生活本身就是副本。

| 常规叫法 | Habitica 叫法 |
| --- | --- |
| 打卡 / 坏习惯 | 习惯（可正可负，反向扣血） |
| 每日任务 | 每日（漏了扣血） |
| 一次性待办 | 待办事项 |
| 奖励 / 商店 | 奖励（花金币买） |
| 金币 | 金币（只能靠做事赚） |
| 等级 | 等级（升级回血） |
| 职业 / 技能 | 职业（战士 / 法师 / 盗贼 / 治疗师） |
| 收集养成 | 宠物 / 坐骑 |
| 组队 | 组队 / 副本 |
| 失败 | 死亡（掉金币装备，但等级保留） |

- **可搬的机制**：**闭环**（金币只能靠做事赚、奖励必须花钱买）；**惩罚"痛而不狠"**（掉东西但不删档）；**反向习惯扣血**；从个人待办升级到**团队协作**。
- **适合**：它与人升 / ulives **同构**，最适合拿来对照自己的设计。

### 8. 地球 Online（Earth Online）

- **世界观**：**不是真游戏** —— 是网友用游戏术语解构人生的梗文化：强制登录、无法退游、不能删档、开局随机、**一命通关**。好处是：**世界观现成、全民共识，不用自己编**。

| 常规叫法 | 地球 Online 叫法 |
| --- | --- |
| 用户 | 玩家（建号 / 开局 / UID = 身份证） |
| 每日任务 | 日常任务（吃饭 / 通勤 / 打卡） |
| 长期目标 | 主线任务（升学 / 成家 / 立业 / 买房） |
| 支线 | 支线任务（恋爱 / 旅行 / 爱好） |
| 意外机会 | 隐藏任务 |
| 限时活动 | 假期 / 节日 / 双十一 |
| 社会事件 | 世界任务（疫情、灾害…） |
| 金钱 | 金币 |
| 成就 | 成就系统（"30 岁前第一次 XX"） |
| 生病 / 倒霉 | debuff / BUG |
| 失眠 | 服务器爆满 |
| 熬夜加班 | 肝 |
| 靠家境 | 氪（"充值通道按出生锁死"） |
| 天赋 / 运气 | 欧 |
| 走捷径 | 挂（"见刑法"😄） |
| 房子 / 车 | 装备 |
| 穿搭 / 医美 | 皮肤 |
| 睡觉 / 起床 | 下线 / 登号 |
| 死亡 | 永久删档 |
| 父母 / 朋友 / 警察 | 老玩家 / 队友 / GM |

- **可搬的机制**：
  - **初始四维**：体力 / 智力 / 魅力 / 财富 —— 开局属性，天然适合做"属性面板"。
  - **变强五梗**：肝（努力）/ 氪（资源）/ 欧（运气）/ 高（特长）/ **避挂** —— 直接当**复盘维度**。
  - **"一星差评体"**当复盘模板：`【人升】★☆☆☆☆ 今日副本太肝，差评`。
  - **NPC 觉醒文学**当激励语："切换玩家模式，夺回主视角"设成开机提醒。
- **适合**：**零成本入戏** —— 不用学任何新设定，谁都能立刻懂。
